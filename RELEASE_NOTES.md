# Haspr Browser Extension v5.18.0

Initial minor release of the **Haspr** browser extension, delivering seamless cryptographic password management, quick access, autofill, and native messaging integration with `go-haspr-cli`.

## What's Changed
- **Rebranding to Haspr**: Complete refresh of extension branding, logos, assets, and documentation links.
- **Manifest Updates**: Updated gecko add-on ID to `extension@haspr.dev` and configured Manifest V3 (Chromium) and Manifest V2 (Firefox, Chrome MV2, Safari) configurations.
- **Multi-Browser Bundles**: Pre-packaged release archives for Firefox (`haspr-5.18.0-firefox.zip`), Chrome MV3 (`haspr-5.18.0-chromium-mv3.zip`), Chrome MV2 (`haspr-5.18.0-chromium-mv2.zip`), and Safari (`haspr-5.18.0-safari.zip`).
- **Documentation**: Added documentation for development, local extension loading, and macOS/Safari self-installation.
- **CI / CD**: Added automated GitHub Actions release workflow that builds extension packages and publishes release assets.
