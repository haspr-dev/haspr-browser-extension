# Haspr Browser Extension v5.18.1

Release v5.18.1 updates extension name and description translations across all locale catalogs.

## What's Changed
- **Locale Translations Fixed**: Renamed application name and description in all 17 supported language catalogs (`de`, `fr`, `es`, `it`, `ja`, `ko`, `nl`, `pl`, `pt`, `ru`, `sv`, `cs`, `lt`, `ro`, `sl`, `uk`, `en`) from Passbolt to Haspr.
- **Store Packages & Releases**: Fully updated packages with clean Haspr branding on all locales.
